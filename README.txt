نصب فلش‌کارت لغات به‌صورت اپ واقعی (PWA)

۱) پوشهٔ این فایل‌ها را روی یک هاست ایستا با https قرار دهید
   (مثلاً GitHub Pages، Cloudflare Pages یا Netlify Drop؛ فقط کافی است همین فایل‌ها بالا بروند).
۲) لینک را در Chrome (اندروید) یا Safari (آیفون) باز کنید.
   اندروید: منو ⋮ ← Install app    آیفون: Share ← Add to Home Screen
۳) بعد از اولین باز شدن، اپ بدون اینترنت هم کار می‌کند.
۴) برای ساخت فایل APK/AAB اندروید، لینک هاست‌شده را در pwabuilder.com وارد کنید.

نکته‌ها:
- با باز کردن مستقیم index.html از فایل‌های گوشی نصب انجام نمی‌شود (نیاز به https).
- در این نسخه پیشنهاد خودکار معانی (هوش مصنوعی) وجود ندارد؛ از دکمهٔ Longman و افزودن دستی استفاده کنید.
- برای به‌روزرسانی، در sw.js عدد fc-v1 را به fc-v2 تغییر دهید.
